# The knowledge arc

How knowledge should be structured, so that what one person understands reaches whoever needs it next, is not cracked. This arc is the search for it. It has produced enough to be used, and this page says what stands and in what order to take it.

[The code](code.md) is the law, and the place to start. It gives what knowledge is made of, the gradient it is laid by, and the few principles that follow from them. One reading leaves you able to write under it.

[The practice](poc.md) is the code worked in the simplest medium there is, markdown files in folders tracked in git. It answers by observation what the code leaves open: how briefs divide, how deep they go, what the entry of a structure looks like.

[The skill](skill.md) is the smallest of the three, and the last one you need. It says what a session does with those files, in prose rather than in code, so that it writes the script it needs at the moment it needs it.

[The study](study/README.md) is where all of this is being found, and where it is still owed. Ten labs so far on one shared corpus, each rewriting the same material under an edition of the code and reading the result cold. It holds what the labs settled, what they have not, and everything authored beside them.
