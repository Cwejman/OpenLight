# What it reads

The surface is given a path in a git working tree, and what lies under that path is the whole of what it knows. It never reads above it. A repository, a folder inside one, or a single file are all valid roots, and the root is the body.

It digests only what says it is knowledge. [The stamp the practice gives a file](../poc.md#9-a-file-says-it-is-under-the-code) marks it, and everything else stays a file the surface leaves alone. So a directory is onboarded a file at a time, and a writer's intent lives in the file rather than in a program's guess.

## 1. A brief and a level are the practice's

What counts as a brief, and what nests beneath it, is [the practice's answer](../poc.md#1-the-medium) and the surface only reads it. Briefly: a brief is a markdown file or a section in one, a folder is a holon whose brief is its entry file, and a document nests its headings below its title.

A level is what stands beneath one brief, so it is the files and folders beside an entry, or the headings beneath a title. The filesystem's divisions and a document's own nesting are therefore one structure, and a descent crosses from folder to file to section without the reader meeting a boundary they did not care about.

*Reasoned; the mapping is the practice's and is pointed at rather than restated, save the one sentence a reader needs to go on.*

## 2. A record is not a holarchy

The stamp also says what kind of file it is, because reading a record by the gradient reads it wrongly. A record's order is chronology, and its sections are occurrences rather than briefs ranked by importance.

So a record is shown as the sequence it declares itself to be, in the order it declares, and never descended as though its entries were parts of a whole.

*Seen.*

## 3. What a weight is

Every figure the drawings show is one of two counts. What a brief **owns** is its own prose. What it **totals** is that plus everything beneath it. Nothing else is counted, and the two are never mixed in one mark.

Both are counted in tokens, and a token here means four bytes, which is the method [the study's own records use](../study/measured.md#1-the-study-against-the-gradient-2026-09-12) because no tokenizer is assumed present. It is an approximation, and it is named because every mark in every drawing rests on it.

*Reasoned; the approximation is the labs' own and is carried here without being improved.*

## 4. What a link gives, and what points back

A link in a brief's prose is a relative markdown link, and the surface resolves it to the brief it names. A link that leaves the body says so rather than being followed. A link written empty is a brief not yet written, which [the code allows](../code.md#43-work-in-progress), and it is shown as the offer it is rather than as a fault.

A brief also says what points at it, which no pane can give, since a link may reach anywhere and a pane only ever descends. That wants one index over the whole body, built when the body is read and kept as the body changes.

*Reasoned, 2026-09-12.*
