## 7. Verdict

Not settled enough to build the platform on; settled enough to build the code's half. The code words (comprehension, win, brief, ground, link, gradient, knower, medium, word) hold together and a reader can act on them. From Space downward the words are specified by metaphor and citation, with dimension, type, protocol, format and boundary expression never given, and four outside documents doing the real grounding. The one change: give the platform words their ground in this file or link it — define dimension, type and the boundary expression concretely, and name the four documents this file leans on.
