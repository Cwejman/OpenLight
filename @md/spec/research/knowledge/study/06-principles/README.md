# Lab 06 — the code as the instruction

The lab that changed how a lab is delivered. Until here the prompt carried the rules and the code stood behind it. Here the prompt went bare and a full edition of the code became the writer's primary instruction, so that what the writer followed and what the study believed were the same document.

That edition is also where the unit was renamed. Fold gave way to brief, and the handing register that came with it, to brief and to debrief, entered the law.

[The edition](code.md) is the law this lab ran under and the first to be written as one. [The prompt](prompt.md) carries only mechanics, which is the point. [The piece](output.md), *The ground others hold*, runs about 5,200 words.

The pattern this lab's output showed, one shape repeating at every heading level, is what [lab 07](../07-breakdown/README.md) was cut to test.
