# What it serves

The program serves a substrate and nothing else. It is given a path in a git working tree, and what lies under that path is the whole of what it knows; it never reads above it. A repository, a folder inside one, or a single file are all valid roots, and the root is the whole.

That independence is the point. The program knows nothing of harnesses, sessions or transcripts. Whatever wants to be read by it becomes substrate first, and a session that wants to be readable writes itself into the tree rather than being read out of a log.

*Reasoned, and built: the program takes a path and will not read above it.*

## 1. A file declares itself

A repository holds much that is not knowledge, so the program digests only what says it is. Frontmatter at a file's head stamps it as written under the code, and everything else stays a file the program leaves alone.

This is what lets a directory be onboarded a file at a time, and it is what a published site would digest. The writer's intent lives in the file rather than in the program's guess.

*Seen; the stamp's own form belongs to [the practice](../../poc.md) and is open there.*

## 2. A record is not a holarchy

The stamp also says what kind of file it is, because reading a record by the gradient reads it wrongly. A record's order is chronology and its sections are occurrences, not rooms ranked by importance.

So a record is shown as the sequence it declares, in the order it declares it, and never descended as though its entries were parts of a whole.

*Seen.*

## 3. A room is the unit

A room is a holon: a folder, a file, or a section inside one, each a whole that can be read alone and a part of the whole above it. A folder's own prose is its entry file, a file's is its title and preface, and a section's is whatever stands before its first subheading.

What a room **owns** is that prose. What it **totals** is that plus everything beneath it. Every weight in the program is one of those two, counted in tokens, which here means bytes over four.

So the filesystem's divisions and a document's own nesting are one structure, and a descent passes from folder to file to section without changing kind. The program says which boundary it crossed rather than flattening them.

*Reasoned; the token approximation is stated because every figure rests on it, and it is the one the labs' own records use.*
