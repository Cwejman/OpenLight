## 1. Webstrates / Codestrates / Varv — Aarhus (Klokmose, CAVI)

**Varv concept (verified from primary docs, https://varv.projects.cavi.au.dk/docs/guide/concept-language/, fetched 2026-08-26):** the unit of composition is the **concept** — "A concept is an individual named unit of interactive behavior, for instance, a 'todo' in a todo list application." Each concept holds a **schema** ("defines the shape of the state of a concept... using named **properties**"), **actions** (an optional when-block plus a required then-block), and **triggers** (reactive triggers on property state changes; view triggers on input events in the view). Extension is first-class: multiple concept definitions merge, and four operators — `inject`, `join`, `pick`, `omit` — compose them. The extensions page states verbatim that `inject` "takes one or multiple source concepts and one target concept, and injects the source concepts into the target concept, leaving the source concepts unaltered." Site framing: "Any Varv program can be extended or modified with new features or capabilities without changing the original source code."

**Paper verified:** *Varv: Reprogrammable Interactive Software as a Declarative Data Structure*, Borowski, Murray, Bagge, Kristensen, Satyanarayan, Klokmose — **CHI '22**, DOI 10.1145/3491102.3502064 (listed on both varv.projects.cavi.au.dk and https://webstrates.net/project/publications/). Your guess was right.

**Repo status (gh api, 2026-08-26):** `Webstrates/Varv` 14 stars, last push **2024-10-23**, all recent commits are `CAVI-Jenkins: Automatic commit` (build artifacts, not development) → **dormant**. `Webstrates/Codestrates-v2` last push 2025-09-29, 11 stars. Original `Codestrates` untouched since 2018. codestrates.org 301-redirects to codestrates.projects.cavi.au.dk.

**But the platform itself is alive:** `Webstrates/Webstrates` — 273 stars, pushed **2026-08-18**, human commits (Marcel, svnhub) through Nov 2025/Aug 2026; note no release since **v1.7.0 (2019-06-27)**. Successors exist: **MyWebstrates** (25 stars, pushed 2026-04-23, commits by Klokmose himself; README: "presented at UIST 2024... reimplementation of Webstrates designed to work as local-first software" using Automerge, collaboration with Télécom Paris, IP Paris and **Ink & Switch**; public host my.webstrates.net) and **Spatialstrates** (pushed 2026-04-28, "Cross-Reality Collaboration through Spatial Hypermedia", WebXR, built on Webstrates+Codestrates+Varv), plus DashSpace (2025-10). The webstrates.net publications page lists **nothing after 2022** — it is stale relative to the repos.

**Grade:** Webstrates core = research-prototype, actively maintained. Varv = research-prototype, dormant since 2024. Codestrates = dormant. MyWebstrates/Spatialstrates = active research-prototypes (the successor line). Third-party traction is negligible: HN's best Webstrates thread is 12 points/4 comments from 2015 (hn.algolia.com search).
